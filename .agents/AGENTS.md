# Workspace Rules & UI Guidelines

All design, style, and layouts for pages created in this workspace MUST be based on the saved seller dashboard UI.

## UI Design Guidelines

### 1. General Page Layout & Structure
- **Sidebar**:
  - Position: Left-aligned with a white background.
  - Fonts & Text: Dark gray text, light gray dividers, and subtle icons.
  - Badges: Custom indicator badges for sidebar items (e.g., Red circular/pill notifications such as "99+", "2").
  - User profile section: Nest user info (Avatar, Name, Email) at the bottom in a rounded block.
- **Header**:
  - Simple breadcrumb or screen name indicator at the top left in small, muted gray text.
  - Title in bold, prominent, modern sans-serif typography (e.g., Inter, Roboto, or Outfit) with dark navy/slate coloring.
  - Right-aligned filters or controls formatted as rounded pills/buttons (e.g., Date pickers, drop-downs with icons).

### 2. Styling, Cards & Colors
- **Color Palette**:
  - **Primary Accent**: Vibrant Royal Blue (approx. `#2563eb` or `#0052ff`) used for active states, key CTAs, and highlight cards.
  - **Background**: Page background should be an extremely clean light-gray/slate (`#f8fafc` or `#f4f4f5`).
  - **Card Background**: Pure white (`#ffffff`) surfaces.
  - **Borders**: Thin, soft gray-blue borders (`#e2e8f0` or `#f1f5f9`).
  - **Aesthetics**: Glassmorphism highlights, modern subtle shadows (`shadow-sm` or `shadow-md`), and vibrant gradients (Royal Blue to Sky Blue gradient flows).
- **Cards**:
  - Must have generously rounded corners (`border-radius: 16px` to `24px` / `rounded-2xl` to `rounded-3xl`).
  - Clean padding and consistent structural grids.
  - KPI Stat cards include trends in small rounded badges (Green `↗ 27%` for positive, Red `↘ 14%` for negative).
  - Include micro-charts/sparklines inside stats cards where appropriate.

### 3. Component Details
- **Active States / Highlighting**:
  - Important status, selected action, or key funnel steps should be completely filled with the primary Royal Blue color with white text.
- **Funnel / Progress Indicators**:
  - Multi-step layouts or progression flows should use smooth gradient indicator bars with curved endpoints.
- **Charts & Visualizations**:
  - Doughnut charts with centered total counts.
  - Linear horizontal progress bars with distinct color segments (e.g., blue, teal, orange) to represent distributions.
